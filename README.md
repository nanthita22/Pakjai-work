PAJAI WORK - GitHub Pages deployment (free)

1. Sign in or create a GitHub account at https://github.com
2. Create a new repository. Name it pajai-work. Set visibility to Public.
3. Upload index.html from this folder to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. GitHub Pages will show your website URL, usually:
   https://YOUR-USERNAME.github.io/pajai-work/
8. Open the link on your phone. In Chrome Android use menu -> Add to Home screen.

IMPORTANT DATA NOTE:
This version uses browser localStorage. It stores records on the device/browser used.
The online link is accessible from other devices, but saved shifts do NOT automatically
sync between devices. Export/import backup is included in the website.
For private personal use, do not publish sensitive notes. GitHub Pages site is public.
